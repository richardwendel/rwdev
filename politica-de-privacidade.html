Política de Privacidade

Como a RWDEV trata dados pessoais recebidos pelo site e canais de atendimento.

LGPD

Tratamento de dados com finalidade clara

A RWDEV utiliza os dados enviados pelo formulário de contato, WhatsApp, Instagram ou e-mail apenas para responder solicitações, preparar orçamentos, prestar suporte e dar andamento a serviços contratados.

Dados que podem ser tratados

Podem ser tratados dados como nome, e-mail, telefone, serviço desejado, mensagens enviadas pelo usuário e informações necessárias para atendimento técnico ou comercial.

Finalidades

Os dados são usados para atendimento, retorno de contato, elaboração de orçamento, comunicação sobre serviços, suporte técnico, execução de contratos e organização interna das solicitações recebidas.

Compartilhamento

Ao usar botões ou formulário com envio pelo WhatsApp, os dados são direcionados para a plataforma WhatsApp, sujeita às políticas próprias da Meta. A RWDEV não vende dados pessoais e não compartilha informações com terceiros para fins comerciais externos.

Cookies e armazenamento local

O site pode usar armazenamento local do navegador para lembrar o ponto da trilha sonora do site. Esse dado permanece no dispositivo do usuário e não é usado para identificação comercial ou rastreamento publicitário.

Direitos do titular

O titular pode solicitar confirmação de tratamento, acesso, correção, atualização, eliminação ou informações sobre seus dados pessoais, conforme a Lei Geral de Proteção de Dados Pessoais.

Contato para privacidade

Para dúvidas ou solicitações relacionadas a dados pessoais, entre em contato pelo e-mail rwdevtech@gmail.com ou pelo WhatsApp informado no site.

Atualização

Esta política pode ser atualizada para refletir melhorias no site, mudanças nos serviços ou novas orientações legais. Última atualização: 21 de maio de 2026.
